Biblioteca Personal

Descripción del Proyecto

Este proyecto es una solución integral para amantes de la lectura que desean digitalizar su colección física. Permite un control exhaustivo de cada obra, desde la ficha técnica (ISBN, Editorial, Páginas) hasta el seguimiento emocional y logístico de la lectura.

🟡 DESEADO (Control de Precios) 🔵 LEYENDO (Capítulo Actual) 🟣 LEÍDO (Valoración ★)

Funcionalidades

  • Gestión Dinámica: Formulario que adapta sus campos según el estado del libro.
  • Portadas Reales: Sistema de subida de imágenes al servidor local.
  • Panel de Admin: Acceso restringido (ID 2) para visualización total de tablas SQL.
  • Auto-Migración: Script en config.php que asegura la integridad de la BD automáticamente.

Tecnologías

PHP 7.4+ MySQLi Tailwind CSS JavaScript Google Fonts

Desarrollado bajo entorno Linux Ubuntu con arquitectura cliente-servidor.
