01 Descripción

Plataforma de gestión contable y empresarial orientada a la automatización de procesos laborales en PYMEs chilenas. Purfly procesa registros de asistencia biométrica en hojas de cálculo y genera automáticamente contratos de trabajo y anexos legales en formato Word (.docx) y PDF.

  • AsistenciaProcesamiento decimal
  • ContratosPlantillas dinámicas
  • ProducciónProcfile & WSGI

02 Funcionalidades

Funcionalidades

  • Arquitectura Modular: Organización mediante Flask Blueprints para separar lógica de asistencia y generación de contratos.
  • Procesamiento de Datos: Conversión de marcas de reloj control biométrico a horas decimales trabajadas.
  • Generador de Documentos: Creación dinámica de documentos de contratación y anexos legales a partir de plantillas.
  • Sistema de Caché: Almacenamiento eficiente con feeds_cache.json para optimización de consultas.

Tecnologías

  • Python 3.10+
  • Flask
  • Pandas / OpenPyXL
  • HTML5 / CSS3
  • Linux Ubuntu

Desarrollado bajo entorno Linux Ubuntu con despliegue preparado para servidores WSGI.
