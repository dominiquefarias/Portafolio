01 Descripción

Aplicación Web Progresiva (PWA) desarrollada para la organización e interacción en eventos temáticos. Incluye capacidad de instalación en dispositivos móviles y de escritorio, soporte de manifiesto web y subida segura de galerías multimedia.

  • PWAInstalable & manifest
  • MultimediaSubida de imágenes
  • Seguridad.htaccess & reglas

02 Funcionalidades

Funcionalidades

  • Soporte PWA: Configuración completa mediante manifest.webmanifest para comportamiento nativo.
  • Gestión de Usuarios: Registro, login y control de accesos restringidos.
  • Carga de Archivos: Subida segura de imágenes al servidor con validación de tipos de archivo.
  • Despliegue Multi-Entorno: Adaptado para producción en hosting InfinityFree y servidor local Apache.

Tecnologías

  • PHP 8.x
  • MySQL
  • Web Manifest (PWA)
  • JavaScript ES6
  • Apache / .htaccess

Desarrollado bajo entorno Linux Ubuntu con despliegue en servidor web Apache.
