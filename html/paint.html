01 Descripción

Este módulo marca el inicio del trabajo con interfaces visuales dentro del ciclo DAM. Se centra en la transición de la programación lógica pura hacia la representación visual, utilizando el elemento Canvas para renderizar formas geométricas, manipular píxeles y entender el renderizado en tiempo real.

02 Conceptos clave

Conceptos clave

  • Renderizado de Primitivas: Creación de líneas, rectángulos, arcos y curvas mediante código.
  • Gestión de Canvas: Manipulación del contexto 2D para el dibujo dinámico.
  • Espacio Cartesiano: Control absoluto de coordenadas y dimensiones en pantalla.
  • Estilos Dinámicos: Aplicación de gradientes, patrones y colores de forma programática.
