01 Descripción

Aplicación web diseñada para la organización académica integral. Permite organizar asignaturas, priorizar entregas, gestionar fechas límite mediante temporizadores en tiempo real y cambiar de idioma de forma fluida.

  • Multi-idiomai18n nativo
  • AsignaturasVinculación relacional
  • PrioridadesSeguimiento dinámico

02 Funcionalidades

Funcionalidades

  • Control de Entregas: Ponderación de tareas por nivel de prioridad y fecha límite.
  • Soporte i18n: Módulo multi-idioma integrado mediante diccionario dinámico (idiomas.php).
  • Autenticación Segura: Registro e inicio de sesión con manejo de sesiones PHP.
  • Panel Interactivo: Modals interactivos y componentes dinámicos en JavaScript.

Tecnologías

  • PHP 8.x
  • MySQL
  • JavaScript ES6
  • CSS3 Custom
  • HTML5

Desarrollado con arquitectura Cliente-Servidor.
