# Portafolio Profesional - Dominique Farías Osorio

Bienvenido al repositorio oficial de mi portafolio web. Este proyecto aloja el código fuente de mi sitio web personal, diseñado para exhibir mis habilidades técnicas, proyectos de desarrollo de software y experiencia en programación.

## 📄 Descripción General

Este repositorio contiene la estructura **HTML y CSS** de mi sitio web, así como los **scripts originales en Python** de los proyectos presentados. El objetivo es demostrar capacidades tanto en el desarrollo web frontend (diseño y maquetación) como en el desarrollo backend (lógica, bases de datos e interfaces de escritorio).

El diseño actual sigue una estética moderna (con variantes minimalistas y temáticas de naturaleza), priorizando la experiencia de usuario y la presentación clara del código.

## 🚀 Proyectos Destacados

El portafolio incluye detalles y demostraciones de los siguientes desarrollos:

### 1. 🐉 Simulador de Dragones (Estrategia)
Una simulación interactiva basada en lógica condicional avanzada y programación orientada a objetos (POO).
* **Concepto:** Gestión de entidades (dragones) que evolucionan según su edad y entrenamiento.
* **Tecnologías:** Python (Lógica pura), Manejo de excepciones.

### 2. 🗂️ Agenda CRUD (Gestión de Datos)
Sistema de gestión de clientes que opera directamente en la consola.
* **Concepto:** Aplicación completa para Crear, Leer, Actualizar y Borrar registros de forma persistente.
* **Tecnologías:** Python, SQLite, Consultas SQL parametrizadas.

### 3. 🖥️ Visor de Clientes (Interfaz Gráfica)
Aplicación de escritorio para visualizar bases de datos empresariales.
* **Concepto:** Panel visual que conecta con una base de datos externa para mostrar información en tiempo real.
* **Tecnologías:** Python, Tkinter (GUI), MySQL Connector, Treeviews.
